# YandexTTS - Yandex синтез речи

![YandexTTS Icon](static/YandexTTS.png)

Синтез речи с использованием API Yandex SpeechKit для преобразования текста в речь.

## Описание

Модуль `YandexTTS` предоставляет возможности синтеза речи для платформы osysHome с использованием API Yandex SpeechKit. Он преобразует текстовые сообщения в аудио файлы речи с поддержкой кэширования.

## Основные возможности

- ✅ **Синтез речи**: Преобразование текста в речь
- ✅ **Выбор голоса**: Множество вариантов голосов
- ✅ **Управление эмоциями**: Управление эмоциями речи
- ✅ **Кэширование аудио**: Кэширование сгенерированных аудио файлов
- ✅ **Множество форматов**: Поддержка формата MP3

## Панель администратора

Модуль предоставляет административный интерфейс для:
- Настройки параметров API
- Выбора голоса и эмоции
- Тестирования синтеза речи

## Конфигурация

- **Access Key**: Ключ доступа API Yandex SpeechKit
- **Speaker**: Выбор голоса (по умолчанию: tatyana_abramova)
- **Emotion**: Эмоция речи (по умолчанию: good)

## Доступные голоса

- **tatyana_abramova**: Женский голос
- Другие голоса доступны в Yandex SpeechKit

## Доступные эмоции

- **good**: Нейтральная/хорошая эмоция
- **evil**: Злая эмоция
- **neutral**: Нейтральная эмоция

## Использование

### Синтез речи

Используйте действие `say`:
```python
callPluginFunction("YandexTTS", "say", {
    "message": "Привет, это тест",
    "level": 0
})
```

## Технические детали

- **API**: API синтеза речи Yandex SpeechKit
- **Формат**: Аудио формат MP3
- **Кэширование**: Кэширование файлов на основе MD5 хэша
- **Язык**: Русский (ru_RU)
